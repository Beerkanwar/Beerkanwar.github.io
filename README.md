# Beer Studios Portfolio Website

This is the source code for the interactive portfolio website of Beerkanwar Singh. 

Built with:
- Astro 5
- Vanilla CSS
- TypeScript

## Features
- Fully responsive 8-bit / dark mode UI
- Dynamic case files and SVG blueprint generation for missing assets
- 60-second Recruiter Mode
- Hidden Konami Code and 404 Snake mini-game
- Interactive Achievement System

## Scripts
- `npm run dev` - Start development server
- `npm run build` - Build the static site
